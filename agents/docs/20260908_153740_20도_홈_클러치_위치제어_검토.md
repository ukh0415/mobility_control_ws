# 20도 홈 클러치 위치 제어 가능성 검토

## 발생 시각과 환경
2026-09-08 15:37:40 KST. 사용자 설명: a=링기어 고정, b=캐리어 고정.
a에서 모터2 300°로 캐리어 20°, b에서 모터2 240°로 링기어 20°.
양 부품의 홈 간격은 20°, 클러치에는 센서를 설치하지 않을 계획.

## 사용한 코드 버전 또는 Git 커밋
HEAD 207cdd5 및 현재 작업 트리. 기존 사용자 변경 유지.
참조: 휠_트랙_모드_전환_시퀀스.md, protocol/protocol.md, main.c.
이번 작업은 설계 검토 문서만 추가하며 코드/규격/배선은 수정하지 않는다.

## 증상
현재 모터2는 j/l의 고정 PWM 구동이며 목표 카운트 위치 제어가 없다.
센서 없는 클러치의 정렬과 체결 판정을 어떻게 구현할지 미확정.

## 재현 절차
설계 검토 요청으로 실기 재현 없음. a/b 고정 조건과 모터2 측정값으로 계산했다.

## 기대 동작
각 부품의 홈을 외부 클러치 기준 위치에 정렬한 다음 정지 상태에서 체결한다.

## 조사 내용과 측정값
모터2 기존 사용자 측정: (806+789+809)/3 = 801.333333 count/rev.
이 값의 기준 축이 이번 300°/240°의 모터축과 같다는 조건으로 계산한다.
모터1 측정값은 이 계산에 사용하지 않는다.

| 상태 | 출력 20°당 모터각 | 목표 계수 변화 절댓값 | 출력각/count |
|---|---:|---:|---:|
| a, 링 고정 | 300° | 801.333333×300/360 = 667.777778 | 360/(801.333333×15) = 약 0.029950° |
| b, 캐리어 고정 | 240° | 801.333333×240/360 = 534.222222 | 360/(801.333333×12) = 약 0.037438° |

숫자는 이론적 계수 분해능이며 출력축 정확도 보증이 아니다. 백래시, 탄성, 정지 오차,
초기 홈 위상, 측정 오차 및 회전 방향을 확인해야 한다. 15/12는 사용자 제공 전체 감속비로
취급했으며 기어 잇수와 추가 감속단으로 독립 검증하지 않았다.

## 원인
엔코더 펄스는 이동량 측정 신호이며 모터에 300° 회전을 지시하는 구동 펄스가 아니다.
모터 엔코더만으로 클러치 삽입 깊이나 완전 체결 여부를 직접 관측할 수 없다.
한쪽 고정이 풀리고 다른 쪽도 체결되지 않은 중립에서는 기존 단일 고정 감속비를 적용할 수 없다.

## 해결 또는 임시 조치
검토안이며 미적용:

1. 홈 기준각을 각각 정하고 목표를 theta_offset + 20°×정수로 관리한다.
   20° 간격만으로 절대 홈 위상은 알 수 없다. 부팅 시 수동 기준 맞춤/체결 확인을
   하거나 검증된 기계 원점 구조가 필요하다. 임의 카운트 0은 기계 원점이 아니다.
2. STM32에서 일정 주기의 목표 카운트 오차→속도/PWM 제어를 수행한다.
   목표 근처 감속, 위치 허용오차와 저속 상태의 일정 시간 유지, 출력 제한,
   시간 초과/무응답 정지 및 로컬 통신 watchdog을 포함한다.
3. 반복 이동마다 668/534를 무조건 더하지 않고 기준+누적 목표각으로 계산 후 반올림한다.
4. a→b: 모터1 정지 확인→a 유지 중 캐리어 목표 홈 정렬→모터2 정지 확인
   →모터3 전환→b 체결 확인→트랙 주행.
5. b→a: 트랙 감속→b 유지 중 링기어 목표 홈 정렬→모터2 정지 확인
   →모터3 전환→a 체결 확인→캐리어 휠 기준 복귀.
   기존 문서의 b→a 전에 링기어 정렬 단계가 추가로 필요하다.
6. 링기어 정렬은 트랙 변위를 유발할 수 있다. 목표 홈 선택은 최단 거리뿐 아니라
   허용 이동 방향/차체 이동/단차 지지/4모듈 동기화를 고려해야 한다.
7. 캐리어와 링기어 각도를 별도 유지하며 확정된 a/b 구간의 모터2 변화량만 해당 축에 누적한다.
   전환 후 전체 누적 카운트를 새 감속비로 다시 나누면 과거 이동을 잘못 해석한다.
8. 센서 없는 기계 체결은 스프링 예압, 진입 모따기, 종단 스토퍼, 위치 유지 구조,
   전환 중 외력에 의한 회전 억제와 완전 체결 전 구동을 막는 기계 인터록의 검토가 필요하다.
   구체 치수와 하중 검증 없이 성공을 보장할 수 없다. 단순 시간 구동 또는 전류 상승은
   걸림/부분 체결과 정상 체결을 단독으로 구별하지 못한다.
9. 기존 규칙상 모터3 동작 중 모터2 회전 금지. 체결 중 모터2를 흔드는 탐색은 제안하지 않는다.
   센서 없는 시제품은 수동 확인으로 정렬 시험을 진행할 수 있으나 무인 체결 완료로 선언하지 않는다.

## 검증 결과
계산 및 현재 소스/시퀀스 대조만 수행. 컴파일/업로드/실기 시험 미수행.
모터 측 엔코더의 위치 관측은 간접 관측이라는 일반 원리는

기구 관련 판단은 제공된 설명에서 도출한 검토 의견이며 확정 설계가 아니다.
