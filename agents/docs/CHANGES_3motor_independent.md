# 변경 사항 — 3모터 독립 제어로 재설계

## 배경

기존 코드는 `i`/`,`/`j`/`l` 키가 전부 **바퀴축 모터 하나만** 조작하고 있었음 (좌/우 다리 속도를 다르게 줘서 회전을 만드는 방식이라, STM32 1개만 연결된 지금 상태에서는 `j`/`l`이 사실상 의미가 없었음). 선기어 모터(htim1)는 타이머만 켜져있을 뿐 실제로 조작하는 명령이 아예 없었음.

**목표**: 바퀴축, 선기어, 고정전환 세 모터를 각각 독립적으로 정/역 회전시킬 수 있도록 재설계.

---

## 키 매핑 변경

| 키 | 이전 | 변경 후 |
|---|---|---|
| `i` | 바퀴축 전진 | 바퀴축 **정회전** (동일) |
| `,` | 바퀴축 후진 | 바퀴축 **역회전** (동일) |
| `j` | 바퀴축 좌회전(차동) | **선기어 정회전** |
| `l` | 바퀴축 우회전(차동) | **선기어 역회전** |
| `u` | (없음) | **고정전환 정회전** (신규) |
| `o` | (없음) | **고정전환 역회전** (신규) |
| `f` | 고정전환 모터 1초 자동 구동 후 정지 | **삭제** (u/o로 대체) |
| `1`, `2` | currentMode 값만 변경 | **삭제** (실사용 없어서 정리) |
| `k` | 전체 정지 | 전체 정지 (동일, 세 모터 다 포함) |

## STM32 (`main.c`) 코드 변경

### `ApplyCommand()` 전면 재작성

- `sign`/`isLeftSide` 좌우 부호 로직 제거 (STM32 1개만 연결된 지금은 의미 없음 → 다리 4개 다 연결되면 복원 필요, 아래 "다음에 할 일" 참고)
- `switch(cmd)`에 `j`, `l`, `u`, `o` 케이스 추가, 각각 `htim1`(선기어), `htim2`(고정전환)를 직접 구동
- `f`, `1`, `2`, `modeSwitchActive`/`modeSwitchStartTick`/`MODE_SWITCH_DURATION_MS` 관련 코드 전부 제거 (자동 타이머 방식 → 수동 정/역 방식으로 전환했으므로 불필요)
- `k`(정지)에서 세 모터(`htim1`, `htim2`, `htim3`) 전부 정지하도록 보강 (이전엔 선기어 정지가 누락되어 있었음)

### 빌드 에러 수정

- 최초 전달 버전에서 `SystemClock_Config()`, `MX_GPIO_Init()` 등 CubeMX 표준 함수들의 본문을 실수로 빠뜨려서 `undefined reference` 링커 에러 발생 → 전체 함수 본문 포함해서 재전달, 해결됨

## 파이썬 클라이언트 (`robot_control_client.py` / `_serial.py`) 변경 필요 사항

```python
MOVE_KEYS = {"i", ",", "j", "l", "u", "o"}
TOGGLE_KEYS = set()  # f/1/2 삭제로 토글식 키 없음
STOP_KEY = "k"
```

안내 메시지 줄도 다음과 같이 갱신 권장:

```python
print("i/, 바퀴축 정/역 | j/l 선기어 정/역 | u/o 고정전환 정/역 | k 정지")
```
