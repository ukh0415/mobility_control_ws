## 5. 상세 변경 내용과 이유

### 5.1 전용 폴더 추가

`agents/docs/코드_변경_기록/`을 코드 변경 이력의 기준 위치로 정했다. 기존 설계 문서와 troubleshooting 문서 사이에서 변경 이력이 섞이지 않게 하기 위한 것이다.

### 5.2 KST 타임스탬프 규칙 추가

실제 변경 기록 파일 이름과 첫 번째 제목이 모두 `YYYYMMDD_HHMMSS`로 시작하도록 정했다. 파일 목록만 정렬해도 작업 순서를 알 수 있고 문서 내부에서도 생성 시점을 바로 확인할 수 있다.

### 5.3 안내 문서와 양식 추가

`README.md`에는 기록 생성 기준과 운영 방법을, `TEMPLATE.md`에는 각 기록에 필요한 항목을 정의했다. 새 작업은 양식을 복사해 별도 파일로 작성한다.

### 5.4 저장소 전체 작업 규칙 반영

루트 `AGENTS.md`에 코드 변경 기록을 필수 규칙으로 추가했다. 앞으로 이 저장소에서 작업하는 사람과 AI가 같은 규칙을 먼저 읽고 적용할 수 있도록 하기 위한 변경이다.
