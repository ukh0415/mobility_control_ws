## 2. 변경 목적

고정 PWM 70% 위치 시험에서 목표를 넘는 즉시 state=4로 잠겨 후속 `p/n/r` 왕복 시험을
진행하지 못하는 문제를 해결한다. 목표 통과 후 실제 관성 정지 오차를 터미널에 남기는
시험 전용 관찰 모드를 추가한다.

## 3. 변경 전 동작

기준 748의 +20도 목표는 1416이었으나 count가 1434로 넘어가자 CE_RANGE fault가
발생했다. 최종 count는 1507이었고, fault가 기준을 무효화해 다음 명령이 거부됐다.

## 5. 상세 변경 내용과 이유

- PWM 70%는 유지한다.
- 목표 허용오차 진입 또는 목표 통과 시 `target_reached`를 설정하고 PWM을 0으로 유지한다.
- 관성 이동이 끝나 count가 300ms 안정되면 실제 오차와 무관하게 DONE으로 전환한다.
- 관찰 모드에서는 DONE 후 drift fault를 사용하지 않아 다음 `p/n/r`을 계속 입력할 수 있다.
- 전체 명령/위치 범위 CE_RANGE, 통신, stall, timeout, 역방향 및 모터1 움직임 정지는 유지한다.

## 7. 프로토콜 호환성

wire version 4, 패킷 길이, 상태 ID와 단위는 변경하지 않았다. 완료 판정 의미만 시험용으로
완화했다. PC/ESP32 바이너리는 이전 version 4와 호환된다.

## 8. 안전 영향과 정지 동작

목표 초과와 완료 후 위치 이탈이 fault가 되지 않는 범위 완화가 있다. 대신 목표 통과 즉시
PWM 0을 강제하고 300ms 정지 전에는 MOVING을 유지한다. 이 모드는 오차 수집용이며 자동
클러치 체결 완료 판정으로 사용하지 않는다. 다른 로컬 정지 조건과 ±360도 시험 범위는 유지한다.

## 10. 확인하지 못한 항목

실제 관성 정지 거리의 반복성, p/n 방향별 차이, r 복귀 오차, 여러 회 왕복 후 누적 오차,
홈 중심과 엔코더 목표의 관계는 확인하지 못했다.

## 11. 되돌리기 방법

`CARRIER_OBSERVATION_MODE`를 0으로 바꾸면 목표 초과 CE_RANGE와 DONE 후 CE_DRIFT를
다시 활성화할 수 있다. 재활성화 후 단위 테스트 기대값도 엄격 모드에 맞춰야 한다.

## 12. 남은 위험과 후속 작업

STM32를 빌드·업로드한 뒤 기준 홈에서 z를 다시 수행한다. 각 p/n/r마다 목표 count,
최종 count, `carrier_deg`, 실제 홈 오차를 기록한다. 데이터 수집 후 70% 출력 차단 선행거리와
최종 허용오차를 결정하고 관찰 모드를 제거한다.
