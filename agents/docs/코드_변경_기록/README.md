# 코드 변경 기록 안내

## 이 폴더의 목적

이 폴더는 PC, ESP32, STM32와 공용 프로토콜의 동작에 영향을 주는 변경을 작업 단위별로 추적하기 위한 곳이다.

코드가 “무엇으로 바뀌었는지”뿐 아니라 다음 사람이 변경 이유, 검증 범위와 남은 위험까지 이해할 수 있도록 기록한다. Git diff가 코드의 줄 단위 차이를 보여 준다면, 이 문서는 변경의 의도와 시스템 영향을 설명한다.

## 언제 새 문서를 만드는가

다음 작업을 시작할 때마다 새 타임스탬프 문서를 만든다.

- `pc/`의 Python 소스 또는 실행 설정 변경
- `esp32/`의 Arduino 소스 또는 보드 설정 변경
- `stm32/`의 원본 소스, 헤더, `.ioc`, 빌드·디버그 설정 변경
- `protocol/`의 패킷, 명령, 상태, 단위 또는 호환성 변경
- `tests/`의 테스트 코드나 검증 기준 변경
- 안전 로직, 핀, 타이머, 주소, 센서 환산값 등 실행 동작에 영향을 주는 설정 변경

설명 문서의 오탈자만 고치는 것처럼 실행 동작과 무관한 문서 전용 수정은 필수 기록 대상이 아니다. 다만 설계 결정이나 시험 결과가 달라지는 문서 수정은 기록한다.

하나의 논리적 작업을 진행하면서 여러 번 저장하거나 검증하는 경우에는 같은 기록 문서를 계속 갱신한다. 목적이 다른 후속 작업으로 넘어갈 때 새로운 문서를 만든다.

## 파일 이름과 제목 규칙

한국 표준시(KST)를 사용한다.

```text
파일 이름: YYYYMMDD_HHMMSS_간단한_변경명.md
첫 제목:   # YYYYMMDD_HHMMSS 변경 제목
```

예:

```text
20260908_140530_STM32_명령_타임아웃_추가.md
```

```markdown
# 20260908_140530 STM32 명령 타임아웃 추가
```

Windows PowerShell에서 KST 타임스탬프를 얻는 명령은 다음과 같다.

```powershell
$kstNow = [TimeZoneInfo]::ConvertTimeBySystemTimeZoneId(
  [DateTimeOffset]::UtcNow,
  'Korea Standard Time'
)
$kstNow.ToString('yyyyMMdd_HHmmss')
```

같은 초에 서로 다른 기록을 만드는 경우에는 1초 뒤의 실제 시각을 다시 얻는다. 임의 번호를 뒤에 붙이거나 이미 존재하는 파일을 덮어쓰지 않는다.

## 작성 순서

1. 작업을 시작하기 전에 KST 타임스탬프를 얻는다.
2. `TEMPLATE.md`의 내용을 복사하여 새 파일을 만든다.
3. 변경 목적과 변경 전 동작을 먼저 기록한다.
4. 코드를 수정하면서 대상 파일, 함수·심볼과 변경 이유를 구체적으로 추가한다.
5. 프로토콜과 안전 영향이 없더라도 `없음`과 그 근거를 적는다.
6. 수행한 검증 명령과 실제 결과를 기록한다.
7. 하드웨어에서 확인하지 않았다면 `실기 미검증`이라고 명시한다.
8. 작업 완료 시 남은 위험과 후속 작업을 최종 정리한다.

## 기록 원칙

- 실제로 수행하거나 관찰한 내용과 추측을 구분한다.
- 원인이 확정되지 않은 내용에는 `미확정`이라고 표시한다.
- “테스트 완료”라고만 쓰지 말고 명령, 대상 보드, 성공·실패 결과를 적는다.
- 컴파일 성공과 실제 하드웨어 동작 성공을 구분한다.
- 프로토콜 변경은 `protocol/protocol.md` 수정 여부와 버전 호환성을 적는다.
- 모터 관련 변경은 정지 조건, timeout, 인터록과 실패 시 출력을 반드시 적는다.
- 사용자에게 이미 있던 변경과 이번 작업에서 만든 변경을 구분한다.
- 비밀키, 개인 포트, 인증정보와 불필요한 개인정보는 기록하지 않는다.
- 완료된 과거 기록은 새 작업 내용으로 덮어쓰지 않는다. 사실 오류를 바로잡을 때는 수정 이유와 시각을 해당 문서에 남긴다.

## 문서 찾아보기

파일 이름을 시간순으로 정렬하면 변경 순서가 그대로 보인다.

```powershell
Get-ChildItem -LiteralPath 'agents/docs/코드_변경_기록' -Filter '*.md' |
  Sort-Object Name |
  Select-Object Name
```

`README.md`와 `TEMPLATE.md`는 운영 안내 파일이므로 타임스탬프 규칙의 예외다. 실제 변경 이력 파일에는 반드시 타임스탬프를 사용한다.
