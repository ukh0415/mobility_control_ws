# 모터3 클러치 수동 조그 시험

## 목적과 범위

클러치 위치 센서가 없는 현재 하드웨어에서 모터3의 배선, 방향, 기동 여부와 한 번의 짧은
구동에 따른 기계 이동량을 확인한다. 이 기능은 클러치가 A 또는 B에 완전히 체결됐다고
자동 판단하지 않는다. 사용자가 모터3을 짧게 여러 번 움직이고 실제 기구를 눈으로 확인하는
단일 모듈 시험용이다.

## 기존 하드웨어 설정

이번 작업에서 핀이나 CubeMX 설정은 바꾸지 않았다. 기존 프로젝트에 다음 설정이 이미 있다.

| 기능 | STM32 설정 | 실제 코드 |
|---|---|---|
| 모터3 PWM | `TIM2_CH3`, `PA2` | `htim2`, `TIM_CHANNEL_3` |
| 모터3 방향 1 | `PB8` | 양의 PWM에서 High |
| 모터3 방향 2 | `PB9` | 음의 PWM에서 High |

TIM2는 prescaler 71, period 999로 설정돼 있다. `SetMotor()`는 요청한 PWM 퍼센트를
TIM compare 값으로 바꾸고 PB8/PB9 중 한 핀만 High로 만든다.

## 전체 사용자 키

기존 모터2 위치 시험 키는 모두 유지하고 모터3 조그용 `A`, `B`를 추가했다.
`A`/`B`는 실제 클러치를 움직이는 키이고, `1`/`2`는 모터2의 감속비와 각도 환산식을
선택하는 키다. `1`/`2`를 눌러도 모터3이나 클러치가 움직이지 않는다.

| PC 키 | 내부 명령 | 대상 | 동작 | 사용 조건과 결과 |
|---|---|---|---|---|
| `A` | `u` | 모터3 | +45% PWM으로 A 방향 조그, 최대 400ms | 모터1·2 정지 필요. A 방향은 실기 확인 완료 |
| `B` | `o` | 모터3 | -45% PWM으로 B 방향 조그, 최대 400ms | 모터1·2 정지 필요. B 방향은 실기 확인 완료 |
| `1` | `a` | 계산 모드 | 클러치 A 계산 선택: 링기어 고정, 캐리어 출력, 15:1 | `Space` 후 300ms 이상 정지 필요. 기존 기준점 무효화 |
| `2` | `b` | 계산 모드 | 클러치 B 계산 선택: 캐리어 고정, 링기어 출력, 12:1 | `Space` 후 300ms 이상 정지 필요. 기존 기준점 무효화 |
| `→` | `p` | 모터2 | 선택 출력축의 누적 목표를 +20도 한 칸 증가 | `state=1` 또는 `state=3`에서만 허용 |
| `←` | `n` | 모터2 | 선택 출력축의 누적 목표를 -20도 한 칸 감소 | `state=1` 또는 `state=3`에서만 허용 |
| `↑` | `z` | 기준점 | 현재 기계 홈과 motor2 count를 0도로 저장 | 계산 모드 선택 및 300ms 이상 정지 필요. 성공 시 `state=1` |
| `↓` | `r` | 모터2 | 저장한 0도 홈으로 복귀 | 기준 설정 후 `state=1` 또는 `state=3`에서 허용 |
| `Space` | `k` | 전체 | 모터1·2·3 즉시 정지 | 이동 중 모터2를 정지하면 위치 기준을 다시 잡아야 함 |
| `Esc` | - | PC | 정지 명령을 전송한 뒤 프로그램 종료 | 시험 종료 시 사용 |

문자 키 `p`, `n`, `z`, `r`, `k`도 각각 `→`, `←`, `↑`, `↓`, `Space`와 같은
기능으로 남아 있다. 방향키 사용을 권장한다.

2026-09-17 실기에서 A 키가 클러치 A 방향, B 키가 클러치 B 방향으로 움직이는 것을
확인했다. 클러치 위치 센서가 없으므로 종단 체결 완료 여부는 계속 사용자가 확인한다.

## 한 번 눌렀을 때의 동작

```text
A 또는 B 입력
→ PC가 약 300ms 동안 내부 명령 전송
→ STM32가 새 명령의 첫 변화만 조그 시작으로 인식
→ 모터1·2 정지 여부 확인
→ 모터3 45% PWM 출력
→ 최대 400ms 도달
→ PC나 ESP32 상태와 관계없이 STM32가 PWM 0으로 자동 정지
```

PC의 300ms 전송은 I2C polling에서 명령이 누락되지 않도록 하기 위한 것이다. 실제 모터
구동 상한은 STM32의 `CLUTCH_JOG_DURATION_MS=400`이 결정한다. 같은 문자가 반복 수신돼도
한 번의 조그가 다시 시작되지 않는다. 더 움직이려면 자동 정지와 `motor3_pwm=0`을 확인한
뒤 A 또는 B를 다시 누른다.

## 인터록과 오류

모터3을 시작할 때 다음 조건을 검사한다.

- 모터2 위치 제어 상태가 MOVING이 아님
- 기존 모터3 조그가 끝남
- 모터1과 모터2 엔코더가 300ms 이상 정지
- FAULT에서 재시험한다면 Space 명령을 먼저 받음

조그 중에는 시작 시점의 모터1/2 count를 저장한다. 어느 하나라도 2 count를 초과해
움직이면 `CE_CLUTCH_INTERLOCK=9`, `state=4`로 전환하고 모든 PWM을 0으로 만든다.
통신 오류도 기존과 같이 모든 출력을 정지한다.

모터3 조그를 시작하면 기존 `clutch_mode`, 모터2 기준점과 목표 홈 번호를 폐기한다.
클러치가 움직인 뒤에는 이전 감속비와 기준 위치를 그대로 사용할 수 없기 때문이다.

## 상태 로그

wire version 7 상태는 모터3 PWM과 오류 외에 모터2 목표 count와 실제 PWM도 제공한다.

```text
state=0 clutch=NONE output_deg=0.0 motor3_pwm=45 error=0 motor2_count=...
state=0 clutch=NONE output_deg=0.0 motor3_pwm=0  error=0 motor2_count=...
```

- `motor3_pwm=45`: 실기 확인된 A 방향으로 구동 중
- `motor3_pwm=-45`: 실기 확인된 B 방향으로 구동 중
- `motor3_pwm=0`: 모터3 정지
- `error=9`: 조그 중 모터1 또는 모터2 엔코더 움직임 감지

| state | 의미 | 다음 동작 |
|---:|---|---|
| `0` | 기준 미설정 | 클러치 위치에 맞는 `1`/`2` 선택 후 홈에서 `↑` |
| `1` | 기준 설정 완료, 이동 준비 | `→`, `←`, `↓` 입력 가능 |
| `2` | 모터2 이동 중 | 키를 추가로 누르지 않고 정지할 때까지 대기 |
| `3` | 모터2 이동 및 정지 확인 완료 | 다음 `→`, `←`, `↓` 입력 가능 |
| `4` | 오류로 정지 | `error` 기록, `Space`, 원인 확인, 모드와 기준 재설정 |

## 최초 시험 순서

1. 단일 모듈, 무부하 또는 클러치 링크를 쉽게 관찰할 수 있는 조건에서 시작한다.
2. STM32와 ESP32 version 7을 업로드하고 PC 프로그램을 다시 실행한다.
3. 모터 근처에서 즉시 전원을 차단할 수 있게 준비하고 `Space`를 누른다.
4. 모터1과 모터2가 정지했고 로그의 `motor3_pwm=0`인지 확인한다.
5. `A`를 한 번만 누르고 실제 방향, 움직인 거리, 소리와 걸림을 확인한다.
6. 예상과 반대 방향이면 더 누르지 말고 Space 후 방향 결과를 기록한다.
7. 자동 정지 후 필요할 때만 같은 키를 한 번씩 추가 입력한다.
8. 반대쪽은 동일한 방식으로 `B`를 한 번씩 시험한다.
9. 실제 A 또는 B 위치가 정해지면 `Space → 1 또는 2 → 기준 홈에서 ↑` 순서로
   모터2 계산 모드와 기준점을 다시 설정한다.

## 모터3을 포함한 전체 시험 시퀀스

### 1. 시작과 공통 확인

1. STM32와 ESP32에 wire version 7 코드를 업로드하고 PC 프로그램을 실행한다.
2. 첫 상태 로그가 나타날 때까지 기다린다.
3. `Space`를 누르고 `motor3_pwm=0`, 모터1·2 정지를 확인한다.
4. 단일 모듈과 무부하 조건에서 시험하고 즉시 구동 전원을 끌 수 있게 준비한다.

### 2. 클러치 A 시험: 링기어 고정, 캐리어 20도 제어

```text
Space
→ A를 한 번 입력
→ motor3_pwm=45 확인
→ 400ms 이내 자동 정지와 motor3_pwm=0 확인
→ 부족하면 A를 한 번씩 추가 입력
→ 링기어가 실제로 고정된 것을 눈으로 확인
→ Space
→ 1 입력: 15:1 계산 모드 선택
→ 캐리어를 기준으로 사용할 실제 홈에 맞춤
→ 300ms 이상 완전히 정지
→ ↑ 입력: 현재 홈을 캐리어 0도로 저장
→ state=1 확인
→ → 또는 ←를 한 번 입력
→ state=2 동안 대기
→ state=3에서 실제 20도 이동량과 오차 확인
→ 필요하면 다음 →/← 입력 또는 ↓로 0도 복귀
```

`A`는 클러치를 물리적으로 움직이고 `1`은 그 뒤 모터2에 15:1 환산식을 적용한다.
두 키의 역할을 서로 대신할 수 없다.

### 3. 클러치 B로 전환: 캐리어 고정, 링기어 20도 제어

```text
모터2가 state=3 또는 state=1인지 확인
→ Space
→ B를 한 번 입력
→ motor3_pwm=-40 확인
→ 400ms 이내 자동 정지와 motor3_pwm=0 확인
→ 부족하면 B를 한 번씩 추가 입력
→ 캐리어가 실제로 고정된 것을 눈으로 확인
→ Space
→ 2 입력: 12:1 계산 모드 선택
→ 링기어를 기준으로 사용할 실제 홈에 맞춤
→ 300ms 이상 완전히 정지
→ ↑ 입력: 현재 홈을 링기어 0도로 저장
→ state=1 확인
→ → 또는 ←로 ±20도 시험
→ 매번 state=3을 확인한 뒤 다음 명령 입력
→ ↓로 B 모드에서 저장한 0도 홈 복귀
```

클러치를 A와 B 사이에서 움직이는 순간 이전 계산 모드와 기준점은 자동으로 폐기된다.
따라서 전환할 때마다 반드시 `Space → 실제 클러치 이동 → Space → 1/2 → ↑` 순서로
새 기준을 설정한다.

### 4. 정지와 오류 복구

- 시험을 멈출 때는 `Space`, 프로그램까지 종료할 때는 `Esc`를 누른다.
- `state=4`가 나오면 먼저 `error` 값을 기록하고 `Space`를 누른다.
- 기계 걸림과 모터1·2 움직임을 확인한 뒤 300ms 이상 기다린다.
- 클러치 위치를 다시 확인하고 `1` 또는 `2`를 선택한 다음 해당 출력축 홈에서 `↑`로
  기준을 다시 설정한다.
- `error=9`는 모터3 조그 중 모터1 또는 모터2 엔코더가 2 count를 초과해 움직였다는 뜻이다.

## 한계와 후속 작업

- 위치 센서가 없으므로 종단 도달, 체결 성공, 과압착을 소프트웨어가 구분하지 못한다.
- 400ms와 45%는 현재 조그 시험값이며 실제 최종 필요 시간과 토크는 미확정이다.
- 종단에 닿은 상태에서 같은 키를 반복하면 기구와 모터에 부하가 누적될 수 있다.
- 최종 자동 전환에는 A/B 리미트 센서 또는 위치 센서, 최대 전환 시간, 전류 또는 구속 감지가 필요하다.

## 2026-09-17 모터3 방향 확인과 PWM 조정 방법

- 실기 결과: `A`와 `B`의 모터3 구동 방향이 의도한 클러치 방향과 일치했다.
- 현재 PWM은 `stm32/mobility/Core/Inc/carrier_test.h`의
  `CLUTCH_JOG_PWM_PERCENT`에 정수 퍼센트로 설정한다.
- 값은 10% 단위로 제한되지 않는다. `41`, `45`, `50`처럼 1% 단위로 변경할 수 있다.
- `SetMotor()`가 입력을 -100%에서 +100% 사이로 제한하므로 유효한 크기 범위는
  `0`에서 `100`이다. 이 상수는 방향 부호가 아니라 구동 크기이므로 양수로 둔다.
- PWM을 올려도 한 번 누를 때의 최대 구동 시간은 `CLUTCH_JOG_DURATION_MS=400`으로
  유지된다. PWM과 구동 시간을 동시에 올리지 말고 PWM만 조금씩 조정해 이동량과 충격을 확인한다.

## 2026-09-17 PC 재연결 후 state=None 조치

- 증상: COM7 연결과 Space 전송은 성공하지만 A/B 입력 시 `state=None`으로 거부됐다.
- 원인: ESP32는 I2C 상태를 100ms마다 읽고 있었지만 USB 로그는 상태 변화 때만 출력했다.
  ESP32가 재부팅되지 않은 상태에서 PC만 다시 연결하면 안정 상태 로그가 새로 나오지 않아
  PC가 `state`와 `motor3_pwm`을 초기화하지 못할 수 있었다.
- 조치: 상태 변화 즉시 출력과 이동 중 1초 진행 로그는 유지하고, 안정 상태도 2초마다 한 줄
  다시 출력하도록 했다. I2C 읽기와 제어 주기는 변경하지 않았다.
- PC는 상태를 받기 전 A/B 입력 시 모터2 미정지로 표현하지 않고 상태 수신 대기 중이라고
  안내한다. ESP32 업로드 후 PC를 다시 실행하고 최대 2초 안에 `state=...` 로그가 뜨는지 확인한다.

## 2026-09-17 모터3 조그 이동 시간 추가 측정

- 45% PWM, 250ms 조건에서 A와 B 모두 목표 클러치 위치까지 각각 두 번의 키 입력이
  필요했다. 방향과 기동은 정상이며 한 번의 이동 거리만 부족한 것으로 관찰됐다.
- 두 번의 통전 시간 합은 500ms지만, 한 번에 연속 구동하면 두 번째 기동 손실이 없어
  500ms보다 짧은 시간에도 같은 이동량에 도달할 수 있다.
- 다음 시험은 PWM 45%를 유지하고 `CLUTCH_JOG_DURATION_MS`만 400ms로 변경한다.
- 400ms에서 목표보다 부족하면 450ms, 과하면 350ms처럼 50ms 단위로 조정한다.
- A/B가 서로 다른 시간을 요구하는 것이 확인되면 하나의 공통 시간 대신 방향별 시간을
  분리한다. 현재 관찰에서는 두 방향 모두 두 번 필요했으므로 우선 공통 시간을 사용한다.
- 위치 센서가 없기 때문에 시간 증가는 체결 완료를 보장하지 않는다. 종단에 닿은 뒤에도
  계속 구동되는지 소리, 전류와 기계 충격을 확인하고 종단 구속이 보이면 시간을 줄인다.
